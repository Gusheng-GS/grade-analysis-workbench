# 成绩分析工作台 V0.1.2（Windows x64）· 安全更新

给高中班主任用的**成绩分析工作台**：导入五岳导出的成绩表，自动算出班级与个人的分数统计、
小题得分、知识点短板、名次变化，再用 AI 生成「个人补弱清单」和可打印的训练方案。

这一版**只做一件事：把内置的 Node.js 运行环境升级到安全版本**，没有功能变化。

> ⚠️ **如果你用 0.1.0 或 0.1.1，并且这台电脑会上网、会打开各种文件，建议升级这一版。**

---

## 为什么要更新

Node.js 于 **2026-10-21** 发布安全版本，修复 10 个漏洞，其中影响较大的包括：

- **CVE-2026-111497**：Brotli 解码器中的高危**远程代码执行**问题
- 若干 **TLS 证书校验绕过**
- DNS 相关缺陷

本项目随包分发的运行环境原来是 **v24.19.0（2026-08-03）**，发布时间早于上述修复，
因此**落在受影响范围内**。本版把它换成 **v24.22.1（LTS）**。

先说清楚风险边界，免得过度紧张：

- 这个运行环境**只在本机 `127.0.0.1` 上跑本地服务**，不对外开端口；
- 它不主动访问不可信网站，主要处理你自己导入的成绩文件；
- 但 RCE 类问题一旦被触发后果较重，而升级的代价只是重下一次包，所以**该升**。

> 为什么升到 24.22.1 而不是最新的 26.x：26 是 Current（非长期支持版），
> 安全补丁已经 backport 到 24 的 LTS 补丁版；留在同一条大版本线上，兼容风险最小。

## 这一版有什么变化

| 项目 | 变化 |
|---|---|
| 内置 Node.js 运行环境 | v24.19.0 → **v24.22.1**（官方 LTS 补丁版） |
| 功能 | **完全没变**（界面、导入、分析、AI、更新，都和 0.1.1 一样） |
| 数据 | 不受影响。成绩存在浏览器里，换文件夹也不动 |

升级方法：

1. 下载下面的 zip，解压（得到文件夹「成绩分析工作台」）
2. 把**旧文件夹里的 `data-0.2.1`** 整个拷到新文件夹里（不拷也能用，只是对话记录和密钥要重设）
3. 双击新文件夹里的 `启动.bat`
4. 确认正常后，旧文件夹可以删掉

> 从 **0.1.1 起**就可以用「设置 → 更新」一键升级了：如果你现在用的已经是 0.1.1，
> 直接在里面点检查更新即可，不用手动换文件夹。

## 怎么用

1. 解压到一个**路径不太深**的目录（例如 `D:\成绩分析工作台`）
2. 双击 **`启动.bat`**，等几秒浏览器自动打开（`http://127.0.0.1:3080/`）
3. 第一次用建议先看同目录的 `使用说明.txt`（全中文，里面写了导入、隐私、更新怎么做）

**需要准备：** 一个 DeepSeek API Key（按量计费，很便宜），以及五岳导出的成绩文件夹。

**关于「Windows 已保护你的电脑」**：程序没有商业代码签名证书，第一次运行会拦一下，
点「更多信息」→「仍要运行」。杀毒软件报未知程序同理。

## 数据与隐私（没有变化，重申一下）

- 成绩、名单、方案只存在**你本机浏览器的本地存储**和程序目录，不上传任何服务器
- 只有点「问 AI」时才联网（直连 `api.deepseek.com`），并且默认**先把姓名换成「学生01」这类代号**
- API Key 只存在本机浏览器里
- 换电脑、清缓存前请用「设置 → 数据 → 备份与恢复 → 导出备份」

## 已知限制

- 只支持 64 位 Windows
- 一次只处理一个班级；多次考试之间可以切换、对比
- 需要自己的 DeepSeek API Key（没有 Key 时统计和图表可用，只有「问 AI」不能用）
- 界面依赖浏览器本地存储：换浏览器、清缓存会丢数据（请用备份）
- 自动更新需要能访问 GitHub；访问不了时用「打开发布页」手动下载
- 不支持手机 / 平板浏览器

## 从源码构建

见 [`项目结构说明.md`](https://github.com/Gusheng-GS/grade-analysis-workbench/blob/main/项目结构说明.md)：
`python data\bootstrap.py` 会自动从 npm 拉取 DSH 并组装出可运行的目录；
`python data\get_node_runtime.py --apply` 可以从 nodejs.org 取最新 LTS 运行环境并用官方校验和核对。
