# 成绩分析工作台 V0.1.1（Windows x64）

给高中班主任用的**成绩分析工作台**：导入五岳导出的周测 / 月考 / 期中期末成绩表，
自动算出班级与个人的分数统计、小题得分、知识点短板、名次变化，
再用 AI 生成「个人补弱清单」和可打印的训练方案。

这一版是**从 0.1.0 往后的第一个功能更新**，主要变化是**程序能自己检查并下载更新**，
另外启动方式、安装包命名也统一了。

> ⚠️ **非官方**：本项目与 DeepSeek 没有隶属关系，也不是 DSH（DeepSeek Harness）的官方产品。
> 它只是把 DSH 当作运行外壳，外壳是开源的（MIT），本项目的代码也是开源的（Apache-2.0）。

---

## 这一版新增了什么

### 1. 程序能自己检查更新（设置 → 更新）

- 点右上角 **设置 → 更新 → 检查更新**，会去 GitHub 比对最新发布版
- 有新版本时显示版本号、安装包大小和更新说明，点 **下载并更新** 即可
- **下载在后台进行**：进度条在走，你可以关掉设置窗口继续改卷子、看数据，下好了会弹一条提示
- 下完提示「重启程序后生效」：双击 `停止.bat` 再双击 `启动.bat`，启动器会自动安装并重新注入界面

> 这一步只会向 GitHub 问「最新版是几号」，**不会上传任何学生成绩**。
> 如果这台电脑连不上 GitHub，会自动退化成提示你去发布页手动下载。

### 2. 启动方式统一了：不再有黑窗口

以前双击 `启动.bat` 会弹一个黑色命令行窗口，需要留着不关。这一版把它收掉了：

- `启动.bat` 现在只是把活交给启动器，启动时会闪一个「正在启动」小窗，之后程序在后台跑
- 想关程序仍然是双击 `停止.bat`
- 出错信息不再打在黑窗口里，而是**弹窗提示**，详细过程写在 `_开发文件\启动日志.txt`
- 更新下载的过程另外记在 `_开发文件\更新日志.txt`

### 3. 安装包文件名与 GitHub 一致

GitHub 会悄悄去掉 Release 附件名里的中文字符（原来会变成 `-v0.1.0-windows-x64.zip`），
所以从这一版开始，压缩包统一叫：

```
grade-analysis-workbench-v0.1.1-windows-x64.zip
```

解压出来的文件夹仍然是**「成绩分析工作台」**，双击里面的 `启动.bat` 即可。

### 4. 顺带修掉的问题

- 旧版「有时更新完界面还是旧的」——现在每次启动都会重新注入一次工作台界面
- 旧版更新流程里两处静默失效的地方

## 从 0.1.0 升级到 0.1.1（**这次必须整包替换**）

0.1.0 的启动器里还没有更新代理，**没法自己升级自己**。所以这一次要手动换一次：

1. 下载下面的 zip，解压（得到文件夹「成绩分析工作台」）
2. 把**旧文件夹里的 `data-0.2.1`** 整个拷到新文件夹里
   （不拷也能用，只是之前存的对话记录和 API 密钥要重新设置）
3. 双击新文件夹里的 `启动.bat`
4. 确认一切正常后，旧文件夹可以删掉

**成绩数据不会丢**：成绩存在浏览器的本地存储里，按网址（`127.0.0.1:3080`）区分，
换文件夹不影响。为稳妥起见，升级前建议在「设置 → 数据 → 备份与恢复」里导出一份 JSON 备份。

**从 0.1.1 往后**，就可以用「设置 → 更新」一键升级了，不用再整包替换。

## 怎么用

1. 下载上面的 zip，**解压到一个路径不太深的目录**（例如 `D:\成绩分析工作台`）
   > 包里的文件路径最深接近 200 个字符，放在层层嵌套的文件夹里有可能解压失败。
2. 双击 **`启动.bat`**
3. 稍等几秒，浏览器自动打开界面（`http://127.0.0.1:3080/`）
4. 第一次使用建议先看同目录的 `使用说明.txt`（全中文、无技术术语，里面也写了更新怎么做）

### 系统要求

- Windows 10 / 11，64 位
- 不需要安装 Node.js、Python、数据库
- 只在本机运行（`127.0.0.1:3080`），不对外开端口

### 关于「Windows 已保护你的电脑」

第一次运行时会拦一下，因为程序没有商业代码签名证书。点「**更多信息**」→「**仍要运行**」。
杀毒软件报未知程序也是同理，可以把文件夹加进信任区，或者用源码自己构建。

## 需要准备的东西

- 一个 **DeepSeek API Key**（在 DeepSeek 开放平台申请，按量计费，很便宜）
- 五岳系统导出的成绩表（`各科小题分` / `各科试题分析` / `学生成绩(方向名次)`）

Key 只存在你本机浏览器里，程序不会把它上传到任何地方。

## 已知限制

- 只支持 64 位 Windows，没有 macOS / Linux 版（外壳只有 Windows 打好的包）
- 一次只处理**一个班级**；多次考试之间可以切换、对比
- 需要自己准备 DeepSeek API Key；没有 Key 时统计和图表都能用，只有「问 AI」不能用
- 界面依赖浏览器本地存储：换浏览器、清缓存会丢数据（请用「导出备份」）
- 自动更新需要能访问 GitHub；访问不了时用「打开发布页」手动下载
- 不支持手机 / 平板浏览器
