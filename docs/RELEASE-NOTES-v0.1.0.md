# 成绩分析工作台 V0.1（Windows x64）

给高中班主任用的**成绩分析工作台**：导入五岳导出的周测 / 月考 / 期中期末成绩表，
自动算出班级与个人的分数统计、小题得分、知识点与题型短板、名次变化，
再用 AI 生成「个人补弱清单」和可打印的训练方案。

界面和工作台合并成一个页面，双击就能用；**成绩数据全程只留在你自己电脑上**，
只有点「问 AI」时才会把你选中的内容发出去（默认已自动把姓名换成代号）。

> ⚠️ **非官方**：本项目与 DeepSeek 没有隶属关系，也不是 DSH（DeepSeek Harness）的官方产品。
> 它只是把 DSH 当作运行外壳，外壳是开源的（MIT），本项目的代码也是开源的（Apache-2.0）。

## 怎么用

1. 下载上面的 zip，**解压到一个路径不太深的目录**（例如 `D:\成绩分析工作台`）。
   > 解压路径请尽量短：包里的文件路径最深接近 200 个字符，放在层层嵌套的文件夹里
   > 加上一个很长的文件夹名，有可能解压失败（Windows 的老毛病）。
2. 双击 **`启动.bat`**。
3. 稍等几秒，浏览器会自动打开界面（地址是 `http://127.0.0.1:3080/`）。
   第一次运行时，程序会在同目录生成 `data-0.2.1\`（程序自己的数据）和 `_开发文件\`（启动日志）。
4. 第一次使用建议先点界面里的「使用说明」，或打开同目录的 `使用说明.txt`。

关闭：双击 **`停止.bat`**（只结束占用 3080 端口的那个进程，不动别的程序）。

### 系统要求

- Windows 10 / 11，64 位
- 不需要安装 Node.js、Python、数据库
- 只在本机运行，`127.0.0.1:3080`，不对外开端口

### 关于「Windows 已保护你的电脑」提示

第一次双击 `成绩分析工作台.exe`（或 `启动.bat` 弹窗）时，Windows SmartScreen 很可能拦一下，
因为它没见过这个文件、也没有商业代码签名证书（个人开源项目负担不起）。

处理办法：点「**更多信息**」→「**仍要运行**」。
如果杀毒软件也报，可以把这个文件夹加进信任区——整包内容全部是明文可查的脚本和开源组件，
不相信的话请直接用仓库里的源码自己构建。

## 需要准备的东西

- 一个 **DeepSeek API Key**（在 DeepSeek 开放平台申请，按量计费，很便宜）
- 五岳系统导出的成绩表（`各科小题分` / `各科试题分析` / `学生成绩(方向名次)` 三个 xlsx）

Key 只存在你本机浏览器里，程序不会把它上传到任何地方。

## 数据与隐私

- 成绩、名单、生成的方案：全部存在**你本机浏览器的本地存储**和程序目录里，不上传。
- 发给 AI 的内容：只有你点了「问 AI」的那部分，并且默认会把学生姓名替换成「学生01」这类代号，
  AI 写回来的内容会自动换回真名。可以在「设置 → 隐私」里改。
- 换电脑 / 重装浏览器前，用「设置 → 数据 → 导出备份」存一个 json 文件，到新机器上恢复即可。

## 已知限制

- 只支持 64 位 Windows，没有 macOS / Linux 版（外壳只有 Windows 打好的包）
- 一次只处理**一个班级**；多次考试之间可以切换、对比
- 需要自己准备 DeepSeek API Key，没有 Key 时统计和图表都能用，只有「问 AI」不能用
- 界面依赖浏览器本地存储：换浏览器、清缓存会丢数据（请用「导出备份」）
- 不支持手机 / 平板浏览器

## 更新方法

- 拿到新的**完整包**：解压到新文件夹，把旧文件夹里的 `data-0.2.1\` 拷过去覆盖即可
- 拿到**小更新包**（只有页面文件的那种）：把它放进程序目录的 `update\` 里，
  下次双击 `启动.bat` 时启动器会自动安装

## 从源码构建

见仓库里的 [`项目结构说明.md`](../blob/main/项目结构说明.md)：装好 Node 与 Python 后执行
`python data\bootstrap.py` 会自动从 npm 拉取 DSH 并组装出可运行的目录。
